# Turtle's Tabs Mod Browser

Turtle's Tabs Mod Browser (or TTMB) is a lightweight alternative to the Thunderstore.io TABS page.
It shows all the same mods, but with advanced filters to help you stay clear of nonfunctional or low quality mods.
Filters, UI, and more are built with real feedback from the community in mind.

Try it at the [TTMB Website](https://tabs.turtlewave.dev)! There is no installation; it's hosted as a website using Netlify.

(Note: if you're looking for the blacklists/whitelists, go to /BayTurtleKing/TTMB-Whitelist)
